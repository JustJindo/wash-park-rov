I love ROVs, so I'm making one of my own. My ROV's going to dive to the bottom of Smith Lake in Denver, CO's Washington Park. I created this repository to  record my work and familiarize myself with Git in the process.
If you share an interest in making ROVs, I hope this repository's contents can be of some value to you.

UPDATE 06/13/2026: I tested the first working prototype of my ROV in Smith Lake today! My ROV made it to the bottom of the lake, just upside down. There are a number of buoyancy issues to be addressed, and some water got into the enclosure from an unknown point of vulnerability. Fortunately, all the electronics somehow survived my ROV's first trial run, and I've identified A LOT of new considerations for my next prototype. Here's some [video](https://www.dropbox.com/scl/fi/9tpkhjxywr2wt594vu4l5/washparkrov_0613.mov?rlkey=u6fqotbfxra34d57e7p732cf8&st=nxioff9u&dl=0) from a GoPro I stuck in the ROV's dome port.
